# Neon Getaway — Godot source

This is the source for the Godot 4.5.2 game embedded at `/arcade/demo` and `/arcade`. It starts with a story race across a fictional coastal district: meet Milo, talk, enter the Panther GT, pass seven gates from the city to the forest within about three minutes. At the finish, press E for the original car-heist delivery chapter. The public `Web Demo` export lives in `public/arcade-godot/` and retains one delivery contract; the protected `Web Pro` pack in `game/godot/pro-web/` retains three. Re-export both variants after changing either scene or GDScript. The HUD supports `lang=en|es|pt-BR|nl`.

First run `python game/godot/fetch_character.py` from the repository root. This fetches a pinned, checksum-verified animation-bearing GLB locally. Its raw Mixamo clips are excluded from Git; only the compiled game is distributed. Then open `project.godot` in Godot 4.5.2 and run the main scene. Controls: WASD or arrows to move/drive, E to talk/enter/continue, Space to brake, M to open the original delivery missions at any time, R to restart. The race timer starts only after entering the car. The district has pedestrians with simple role-based routines, moving traffic, a city, highway, broad forest, marina and stylized water. The original delivery chapter remains in `scenes/heist.tscn`. This is still a prototype: the city and NPC schedules are simplified, the finite 2.1 km map is not a GTA-scale open world, driving physics are arcade-like, and there is no spoken dialogue, sound design, mobile controls or globally verified leaderboard.

The story characters use CC0 VitruvianGodot body/head meshes and downscaled textures; the original delivery chapter still uses [GDQuest's Open 3D Mannequin](https://github.com/gdquest-demos/godot-3d-mannequin) under CC BY 4.0. Car meshes are from Kenney's Car Kit 3.1 under CC0. Road and grass textures are CC0 Poly Haven assets. Names, missions and environment layout are original. See `assets/ATTRIBUTION.md`. The Godot AI editor add-on came from the user-provided archive and is MIT-licensed; it is excluded from Web exports.

Godot AI MCP is enabled locally in Codex via `uvx` and was verified against a live Godot 4.5.2 editor (`editor_state` returned ready). Portable Godot, `uvx`, server logs and export templates live in ignored `.tooling/` in the repository root. On a different computer, install Godot 4.5.2, its Web export templates, and [godot-ai](https://github.com/hi-godot/godot-ai) separately. The MCP registration points to this machine's `.tooling` path and is not portable.

For a local export, use the `Web Demo` preset to `public/arcade-godot/index.html` and the `Web Pro` preset to a temporary directory. Copy only the resulting Pro `index.html` and `index.pck` to `game/godot/pro-web/`. The protected route serves the common engine files from the public export. The project uses the GL Compatibility renderer and non-threaded Web template so the page can be embedded without cross-origin isolation. The 38 MB WebAssembly runtime is a material download for mobile visitors.

The browser leaderboard is local and unverified. The Pro package is behind a server subscription check, but any shipped game client can be modified by a determined player. Do not use local scores for prizes or public rankings. A global leaderboard requires server-authoritative scoring and abuse controls.

The circular north-up minimap reads the actual street/building registry and actor positions. CharacterBody3D collision handles walls, trees, pumps and vehicles; vehicle impacts include a brief knockdown and a capped ground stain. The 16-minute day/night cycle drives the sun, sky and street-lamp glow. Shops, a fuel station, market and residential/dock districts expand the city. Repeated static meshes are instanced in 150 m tiles and distant human visuals are culled. The high-detail characters still need profiling on low-end devices; no stable frame-rate guarantee is made.

[OpenWorldJS](https://github.com/obecerra3/OpenWorldJS) was reviewed for chunking, instancing and collision architecture. Its code/assets were not copied (no root license was visible); the implementation remains native Godot. Run the behavior checks with `godot --headless --fixed-fps 60 --path game/godot --script res://tests/story_smoke.gd`. They exercise conversation/entry, movement orientation, wall sliding, impacts, minimap coordinates, day/night and a complete timed race into the original mission scene. The race route test removes ambient traffic to isolate route/timer reachability; this is not a performance benchmark.
